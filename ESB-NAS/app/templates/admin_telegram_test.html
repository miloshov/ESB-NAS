Telegram Direct Test

Test Telegram directly without saving to database. Use this to verify your bot token and chat ID.

Get token from @BotFather on Telegram
For groups: use @myidbot to get correct group ID (starts with -100)
For personal: your Telegram user ID (get from @userinfobot)

How to Get Correct Chat ID

For Groups:

  1. Add your bot to the group
  2. Send a message in the group: @myidbot /getgroupid@myidbot
  3. Bot will reply with the group ID (format: -100xxxxxxxxxx)

For Personal Chat:

  1. Open chat with your bot
  2. Send any message to the bot
  3. Visit: https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates
  4. Look for "chat":{"id":123456789,...}

Common Errors:

  • chat not found - Bot not in group, or wrong chat ID
  • bot was blocked by user - User blocked the bot
  • invalid bot token - Token is wrong
